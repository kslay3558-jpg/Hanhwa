도면 각도 마킹 계산기

높이, 밑변, 대각선, 각도 중 2개만 입력하면 나머지 치수를 즉시 계산합니다. SVG 도면, 입력 상태, 단위 정보까지 한 화면에서 직관적으로 확인할 수 있게 정리했습니다.

정확한 입력 흐름 최근 입력한 2개 항목을 기준으로 계산하며, 3번째 입력 시 가장 오래된 사용자 입력을 자동으로 정리합니다.
도면 중심 UI 삼각형 구조, 각도 마킹, 축 라벨, 보조선과 함께 입력 위치가 시각적으로 연결되도록 SVG를 개선했습니다.
현장 사용성 강화 모바일에서도 카드형 입력이 유지되며, 계산값/직접입력값 상태가 색상으로 즉시 구분됩니다.

직각삼각형 치수 계산

입력 박스를 클릭하면 해당 구간이 SVG에서 강조됩니다. 각도는 우측 하단의 내부 각 기준입니다.

0 / 2 입력됨
높이 mm
밑변 mm
대각선 mm
각도 °
직접 입력한 값 자동 계산된 값
숫자는 양수만 허용되며, 각도는 0° 초과 90° 미만이어야 합니다.
포커스 시 전체 선택되므로 현장 입력 장비에서도 빠르게 수정할 수 있습니다.
추천 입력 조합

밑변 + 높이, 밑변 + 각도처럼 실제 도면에 가장 먼저 확보되는 값 2개를 입력하면 나머지를 바로 확인할 수 있습니다.

입력 오류 방지

빗변은 반드시 다른 변보다 길어야 하며, 계산 불가능한 조합은 즉시 토스트로 안내하고 자동 계산값을 정리합니다.
